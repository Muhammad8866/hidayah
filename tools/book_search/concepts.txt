# Concept dictionary for the in-book search index.
#
# One concept per line:   id: term, term, term
# Every spelling, language and script a reader may type for the same idea goes on one line. A
# query word is turned into its concept, and pages are ranked by how often any term of that
# concept occurs on them, so a Gujarati or Roman Urdu query finds English and Arabic pages.
# Roman spellings only need one or two common forms: build_index.py and the app also match
# close variants (namaz / namaaz / nemaz) by sound.
# After editing, rebuild and re-upload the index; the app picks it up without an update.
